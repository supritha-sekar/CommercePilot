# 5-Minute Pitch Outline

0:00–0:35 — Problem
Merchants have payment and customer data but growth decisions are still manual and reactive.

0:35–1:15 — Product
CommercePilot is an AI growth agent that turns merchant signals into executable growth workflows.

1:15–2:30 — Live demo
Show dashboard → opportunity detection → select win-back opportunity → ask agent → show reasoning, audience, channel, incentive and guardrails.

2:30–3:20 — Agentic architecture
Explain data layer, agent reasoning, structured plan, approval gate and execution API.

3:20–4:15 — Engineering
Explain separation between AI reasoning and deterministic business logic, structured JSON output, guardrails and fallback local agent.

4:15–5:00 — Impact and roadmap
Discuss potential GMV recovery, personalized growth, real payment/campaign integrations, experimentation and learning loops.
