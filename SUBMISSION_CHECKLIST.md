## Demo script

1. Open the dashboard and show revenue, orders, repeat rate and conversion.
2. Explain that the agent has detected high-value opportunities.
3. Open "Win back inactive customers".
4. Generate the agent plan.
5. Explain reasoning, audience, channel, incentive and guardrails.
6. Approve the action.
7. Show the simulated execution log.
8. Explain how real payment/campaign connectors could replace the simulator.
